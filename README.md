# kanban_board

Project Management App with a Kanban board and AI chat.

1. Put `OPENAI_API_KEY=...` in `.env` at the repo root.
2. Start: `scripts/start-server.sh` (or `.ps1` / `.bat` on Windows), then open http://localhost:8000 and sign in as `user` / `password`.
3. Stop: `scripts/stop-server.sh`.
